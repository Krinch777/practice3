## Состав репозитория

| Файл | Назначение |
|---|---|
| `make_test_data.py` | создаёт тестовые данные `company_data/` (3 отдела × 6 CSV-файлов) |
| `backup.py` | резервное копирование в `tar.gz` с SHA-256-манифестом, ротацией (хранит 5 последних копий), проверкой восстановления с отчётом о различиях и восстановлением после инцидента |
| `rpo_rto.md` | расчёт RPO и RTO для типографии (задание 5) |
| `.gitignore` | исключает `company_data/`, `backups/` и `restore_test/` из репозитория |

Нужен только Python 3.12+, сторонние библиотеки не используются.

## Команды запуска

```bash
cd practice1
python make_test_data.py            # 1. создать тестовые данные
python backup.py                    # 2. копия + ротация + проверка восстановления
python backup.py verify             # 3. проверить последнюю копию
python backup.py verify backups/backup_20261117_213352.tar.gz   # проверить конкретную копию
python backup.py restore            # 4. восстановить company_data из последней копии
```
